**Open-source toolkit for building powerful local-first AI agents.** Supports Ollama, MCP, tool calling, multi-agent orchestration. Run everything offline. Built by Grok autonomously!

## ✨ Key Features
- **Local LLMs**: Ollama, vLLM, etc.
- **MCP Protocol**: Standardized agent context.
- **Tools**: Search, code exec, file I/O, browser.
- **CLI & SDK**: Easy to use.
- **Extensible Skills**: Plugin system.
- **Autonomous Mode**: Goal-oriented agents.

## Quickstart

```bash
pip install grok-local-agent-kit ollama duckduckgo-search
ollama pull llama3.2
grok-agent chat "Plan a todo app with FastAPI"
```
